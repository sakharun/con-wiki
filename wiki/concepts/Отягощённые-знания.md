# Отягощённые знания

## Summary
Термин семинара 107: знания и навыки, которые человек приобретает **не по внутреннему интересу, а по необходимости** — чтобы выжить, заработать, удержаться. Они «отягощают» сознание, но именно они дают физическое выживание в период схода с траектории и нередко позволяют позже «стартовать» в самостоятельное дело. Противоположность — неотягощённые знания, которые человек изучает по внутреннему интересу и которые его не отягощают.

## Current Understanding
- **Неотягощённые:** «есть у нас категория знаний неотягощённая. Это то, что по интересу, по внутреннему интересу человеку это интересно изучать. Он учится. Это его не отягощает сознание» (L233).
- **Определение отягощённых:** «это приобретение навыков профессии, знаний, которые приобретаются в событиях, когда человеку неинтересно это. Просто чтобы дальше жить, то есть зарабатывать, для того чтобы там кушать, одеваться, там даже может квартиру купить» (L234).
- **Признак:** «человек работает в напряге постоянно, потому что ему неинтересно, деньги зарабатывает вроде хорошие, но внутреннего удовольствия никакого не получает. Вот это и есть отягощённые знания. Они бывают отягощённые только для сознания человека» (L234).
- **Не отягощение для системы:** «они не системно отягощённые для системы» (L234).
- **Функция при сходе с траектории:** «Отягощающие знания в это время — то, что раньше было отягощающим, — дают возможность физического выживания в этот период» (L242).
- **Часть уровня развития:** сход с траектории возможен, когда у человека есть «наработанные качества совмещения, владение практикой нескольких профессий из разряда отягощённые знания» (L231).
- **Трамплин:** «у многих эти отягощённые знания… фактически дали возможность не только протянуть, а вообще даже многие стартанули с этих отягощённых знаний, которые были неинтересны» (L410); затем «тот потенциал, который не набрали за счёт тех знаний, которые были отягощающими, они уже начали заниматься тем, чем им было интересно» (L410).
- **Связь с комфортом и выживанием:** отягощённые знания — оплата физического существования, пока внутренний интерес не начнёт работать. См. [[Внутренний-интерес]], [[Потенциал]].

## Contradictions / Uncertainty
- **Спектральные / неспектральные (103) vs отягощённые / неотягощённые (107):** две разные оси классификации знаний; сведение не выполнено (Status: требует сведения).
- **«Отягощённые только для сознания человека»** — критерий внутренний и не наблюдаемый извне (Status: лакуна).
- **Пользу отягощённых знаний лектор описывает положительно,** хотя сам термин отрицательный — оценочная двойственность (Status: внутреннее напряжение источника).
- **Нет критерия, когда знание перестаёт быть отягощённым:** при смене интереса или только при выходе на траекторию — не сказано.
